# Portfolio Projects

A collection of portfolio projects showcasing expertise across multiple programming languages, frameworks, and technologies.

This portfolio demonstrates proficiency in full-stack development, mobile applications, desktop applications, and infrastructure management.

## Projects

### 1. 🎮 [Battleship](./Battleship/) - Desktop Game Application
**Technology:** C# | Windows Forms | .NET Framework 4.8

A single-player Battleship game built with C# and Windows Forms. Players position ships and attempt to sink the computer's fleet through strategic coordinate guessing. Features a traditional GUI with intuitive gameplay mechanics.

**Key Skills:** Object-oriented C#, Windows Forms UI design, Game logic implementation

---

### 2. 📚 [Bookstore](./Bookstore/) - E-commerce Platform
**Technology:** Next.js | React | JWT | Contentful CMS

A modern bookstore application featuring JWT authentication, Contentful CMS integration for content management, and a responsive product catalog. Demonstrates full-stack JavaScript development with server-side rendering and API integration.

**Key Skills:** Next.js, React, JWT authentication, Headless CMS, API integration, Modern JavaScript

---

### 3. 💪 [FitTrack](./FitTrack/) - Cross-Platform Fitness App
**Technology:** Flutter | Firebase | Dart | Provider

A comprehensive fitness tracking application built with Flutter, supporting iOS, Android, macOS, Windows, Linux, and web platforms. Features Firebase authentication, cloud data synchronization, and real-time progress tracking.

**Key Skills:** Cross-platform mobile development, Firebase integration, State management with Provider, Dart programming, Material Design

---

### 4. 💼 [Job Website](./Job%20Website/) - Full-Stack Job Portal
**Technology:** Laravel | PHP | PostgreSQL | Docker | React

A full-featured job posting and job search platform featuring:
- Laravel REST API backend
- PostgreSQL database with migrations
- Docker containerization with Docker Compose
- React frontend (if applicable)
- Advanced search and filtering
- Application tracking system

**Key Skills:** PHP/Laravel, Container orchestration, Database design, RESTful APIs, DevOps, Full-stack integration

---
